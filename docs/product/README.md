# Documentação de produto

Esta pasta reúne o plano evolutivo e registra tanto entregas incrementais quanto
propostas ainda dependentes de aprovação. O estado indicado em cada documento é
a fonte de verdade do respectivo escopo.

| Documento | Objetivo | Estado |
| --- | --- | --- |
| [Exame teórico na plataforma](theoretical-exam-plan.md) | Fase 0: identidade do aluno, duas entradas, prova versionada e elegibilidade prática | 0.1 a 0.4 entregues; conteúdo oficial e produção pendentes |
| [Conteúdo dos exames teóricos](theory-exam.md) | Importação, revisão e pendências de mídia dos cadernos oficiais | Templates preparados; revisão e publicação pela administração pendentes |
| [Plano de evolução](evolution-plan.md) | Escopo, fases, critérios de aceite, dados, APIs e UX das próximas versões | Software concluído; ativações externas documentadas |

As decisões estruturais associadas estão em
[`docs/architecture/adr`](../architecture/adr/README.md); cada ADR informa seu
próprio estado.
